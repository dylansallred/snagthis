# Extension motion studies

Four independent UI prototypes for the owner's next extension progress treatment: Signal (rail), Pieces (square segments), Current (flowing light), and Shelf (roomier cards). These are alternatives for review; they do not change the production progress animation.

Serve the repository on localhost and open `/docs/design/prototypes/extension-motion/`. The shared slider, state selector, progress simulation, and effects toggle control every embedded design through `vidsnag-design-state` messages. Each design also opens on its own. Hover or focus a thumbnail to play its actual muted excerpt. No downloader APIs or user downloads are used.

Media reuses the existing Blender open-film excerpts and posters in `apps/extension/popup/media/`; see that directory's `CREDITS.md`. There are no text overlays on the videos. The owner requested multiple directions, including small motion changes and a larger layout change. The root agent owns one coordinated browser check.
