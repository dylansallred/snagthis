How it works

Find it. Snag it. Keep it.

  1. 01

    Find it

    Open the SnagThis popup on any page with a video. It lists what’s playing, with the quality, size and length.

  2. 02

    Snag it

    One click. A plain MP4 or WebM goes straight to Chrome Downloads. Streams go to the desktop app, where every piece fills in as it lands.

  3. 03

    Keep it

    It lands in Saved, a real file in a folder you choose. Play it, find it, or move it anywhere.

Features

Small on the page.
Serious underneath.

Pick the quality. Keep the tracks.

Choose a resolution, an audio language and subtitles before you save. The desktop app merges separate audio and subtitle tracks into one file.

Streams, handled.

HLS and DASH streams arrive in pieces. SnagThis fetches them in parallel, shows each piece filling in, and draws a live speed trace so you always know how it’s going.

⌘K for everything

Pause all, open the folder, search your videos or paste a link, all from the keyboard.

Drop a link to snag it

Drag a link onto the app, or paste one anywhere. SnagThis looks at the page and offers what it finds.

FAQ

Questions

Is SnagThis really free?

Yes. It’s open source under GPL-3.0, with no paid tier and no account. The code is on GitHub.

Do I need the desktop app?

No. The extension saves plain MP4 and WebM files straight to Chrome Downloads by itself. Add the app for streams, separate audio and subtitle tracks, and a Saved library.

Which videos can it save?

Most pages that play a regular video file or an HLS or DASH stream. It won’t save DRM-protected media. Only save videos you own or have permission to save, and follow each site’s terms.

Where do my videos go?

Extension downloads go to Chrome Downloads. The desktop app saves to a folder you choose and lists everything in Saved. Removing a video from the list keeps the file.

How does pairing work?

With the app open, click Connect in the extension, check the four digits SnagThis shows, and choose Allow. Each browser gets its own private token, and either side can disconnect at any time.

When will the extension be in the Chrome Web Store?

Soon. The Add to Chrome button on this page will link to it as soon as it’s live. The desktop app is available now.
