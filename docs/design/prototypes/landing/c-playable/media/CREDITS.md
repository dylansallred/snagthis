# Prototype video credits

These are real excerpts from published Blender Foundation open films, used as sample media in an interactive design study. They are not generated interface animations. No endorsement is implied.

All three clips are licensed [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/). The clips are adapted by trimming to eight seconds, resizing to 480 pixels high, encoding as H.264 MP4, and omitting audio. Each JPEG poster is a frame extracted from its corresponding clip.
