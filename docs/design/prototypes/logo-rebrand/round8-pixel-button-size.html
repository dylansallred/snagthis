SnagThis — round 8 · Pixel bevel, lined up with the letters

The Pixel bevel button sized and placed so it matches SNAGTHIS: its top meets the tops of the capitals and its bottom sits on the baseline. Cyan alignment guides mark the capital line and baseline (toggle them in the Live preview). The S · Button size group also has a one-pixel optical overshoot, the previous 0.88 size for comparison, and button-first / between-words versions at letter height. Every change replays the animation in the app mocks at the top and in the Live preview; add ?slow=4 to watch slowly.

SnagThis

B · Button

The tile and pixel triangle. Each card shows the logo in the top bar, then the app icon at 128, 48, 32 and 16 px (32 and 16 again on white). All use whole grid cells, so the 16 px icon is pixel-exact, except the 24-grid option, which is there to show what happens when the grid is finer than the screen.

A · Animation

Each card plays its own animation with your current button, layout and wordmark. Hover a card’s preview (or press Replay) to play it again. Everything is CSS / Web Animations on the SVG pixels, 400 to 1400 ms; only A11 repeats, and it is optional.

S · Button size

How big the button is next to the words and where it sits. Each card shows a large version and the 22 px top bar; the cyan guides mark the capital line and baseline.

W · Wordmark

Every typeface is scaled so its capitals are the same height, which keeps the button the same size against the words.
