SnagThis — terminal explorations

Building on S9 Terminal. Every part can be changed on its own: how the name is written, syntax colouring, prompt symbol, cursor, monospace font and app icon. Colour, CRT glow, blinking and icon position are in the Live preview panel. Start from a complete logo, or from P0, which is S9 as it was, and fine-tune from there. Replay typing shows the name typing itself out, which could be the app’s startup animation.
