Organise the library · CSmart groups + pins

C · Smart groups + pins

The least new UI. A quiet strip under the header holds one Sort & group button that names the current view (Site · Newest). Grouping by site, date saved, quality or folder adds collapsible headers to the same list, so most organising needs no filing. Folders are lightweight labels (one per video); pinned folders are chips in the strip, and you file a video by dropping it on a chip. Nothing moves on disk.
