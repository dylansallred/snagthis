Chrome popup Settings in TABS, like the desktop, without the scroll.

Five layouts for the popup’s Settings sheet, each at the popup’s real maximum size (480 × 560). Option 1 is today. Choose an option (or press 1–5), switch the connection state, try an accent, and use ← → (↑ ↓ in the rail), Home and End on the tabs. Every control works; nothing is saved.

Recommendation: 3 · Icon tab bar

Build 3 · Icon tab bar. It stays closest to the desktop’s sidebar (the same section names, the same Lucide icons, the same accent marker on the chosen section, and the same arrow-key tablist) and still gives every row the full 480 px, so today’s grouped cards, 132 px selects and swatches move over unchanged. Every tab fits in the 478 px under the tabs in every connection state, so nothing scrolls.

  • Tabs: Downloads · Appearance · Connection · About. Settings opens on Downloads and reopens on the last tab used while the popup is open. Connect entry points open Connection.
  • Disabled rows: one line at the top of the Downloads card says why and offers the fix (Open SnagThis or Connect). The rows only dim. The Connection tab’s small status square repeats the state, and its label reads it aloud (for example, “Connection, SnagThis not open”).
  • Desktop settings: a labelled SnagThis settings ↗ button in the sheet header, visible from every tab. It replaces the link card, so it never competes with rows.
  • Keyboard: role="tablist", roving tabindex, automatic activation, ←/→, Home/End, and Tab into the focusable panel, matching desktop SettingsSheet.
  • Height: keep the popup at the tallest tab’s height while Settings is open, so switching tabs never resizes Chrome’s window.

4 · Compact rail copies the desktop most literally, but at 480 px it squeezes rows to 368 px, which narrows the selects and wraps the notification label. 2 · Segmented is a fine lighter alternative with text-only tabs and no icon echo. 5 · Bottom bar reads as app navigation and sits where the popup’s own footer is.

What stays the same

  • Only browser-relevant settings stay in Chrome (spec §8): Preferred quality, Subtitles, and Tell me when desktop downloads finish, which need a paired and running app. Accent colour works offline. Save folder, speed and the rest remain in SnagThis. There is still no browser-side folder picker and no empty Advanced section.
  • The desktop’s group and row styling (setting-group/setting-row), the green inline Saved, the swatch radio group and the Connection card copy are reused unchanged.
  • Today’s sheet has no version or help. The proposed About tab adds Version 1.0.0, Update Chrome extension (today’s update sheet) and Troubleshooting (the footer’s No video? link).

Prototype only. Nothing connects, saves or opens. Content and copy come from apps/extension/popup.js (showSettings), apps/desktop/src/components/settings/** and docs/design/ui-design-spec.md §5, §8 and §10.
