Pixel worlds

Style 1 of 3 for the demo galleries, README screenshots and website: four original animated pixel-art "videos" drawn on a 320 × 180 grid and shown at 4× (1280 × 720). They use the SnagThis orange family and the pixel bevel play button, which shows up as a billboard, a power-up and the hero of the last clip. Every clip is a seamless 10-second loop.

How they were made

  • Everything is procedural and original. generate.mjs (Node, no dependencies) draws each frame pixel by pixel into a 320 × 180 RGB buffer using the scene code in src/. There are no images, sprites, footage, fonts or audio from anyone else; the 3 × 5 HUD letters are hand-defined in src/lib.mjs. The play button uses the geometry from scripts/render-brand-assets.cjs.
  • Motion loops exactly. Every parallax layer is periodic over its own width, which is its speed × 300 frames. Rain, glints, wheels, enemies and particles are periodic functions of the frame number, so the last frame flows straight back into the first.
  • Frames go to ffmpeg as raw video, get scaled 4× with nearest-neighbour (crisp pixels), and are encoded as two-pass H.264 at 640 kb/s, yuv420p, with +faststart and no audio. Deblocking and psy-rd are turned off so hard pixel edges don't smear. Posters are the same pixels saved as JPEG under 80 KB.
  • To re-render: node generate.mjs (all clips), node generate.mjs neon ocean (only some), or node generate.mjs hop --frames 0,150 (PNG stills to frames/). A full render takes about 15 s.
