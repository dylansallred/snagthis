SnagThisDESIGN STUDIES / TITLE BAR

Custom window chrome: close, minimise, maximise and the title bar.

Today the desktop app sits under the system’s own title bar: a grey strip with the window buttons and “SnagThis Desktop”, then the dark app header below it. Windows also shows Electron’s default File · Edit · View · Window · Help menu. Each option below is shown in a full 960 × 660 window on macOS and Windows. The header and list are the real app from the ?gallery state. Click an option or press 1–7. P switches the platform, I toggles an active or inactive window, and D shows drag regions. Hover over the window buttons; on Windows, rest on maximise to see Snap layouts.

Header, rows and footer come from the running desktop renderer (http://localhost:5173/?gallery) at 960 px. The header is rebuilt in HTML from TopBar.tsx so options can move it. The rows and footer are screenshots.

The Electron settings below were checked against the BrowserWindow options API: titleBarStyle, trafficLightPosition, titleBarOverlay, setWindowButtonVisibility and frame. Pixel offsets still need tuning in a packaged build on each OS.
