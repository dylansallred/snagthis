A · The chip is the whole update UI

Downloads silently. When ready, one accent chip 1.1.0 · Restart sits in the header; clicking it restarts straight away. If downloads are running, a one-line confirm offers Install after 2 downloads finish. The update sheet, Later, reminders and the “downloading” notification go away. After relaunch a toast says Updated to 1.1.0 · What’s new and fades.

Behaviour

  • Idle: 1 click, no confirm. Downloads running: 2 clicks; the one-line confirm defaults to waiting, and Restart now pauses and resumes them.
  • Later / defer: removed. Leaving the chip alone is “later”. It never reminds, blinks or notifies again.
  • Hidden window (macOS): one notification per version, only when no SnagThis window is visible. Clicking it restarts if idle, otherwise opens the window with the confirm.
  • Failures: amber chip → small popover with the same friendly sentence, Download installer ↗, Try again and raw text behind Details.
  • /Applications: no chip ever for an unsupported copy; Settings says why and offers Move to Applications (app.moveToApplicationsFolder()).

Code changes

  • main.js: drop the update-available notification; show the update-downloaded one only when !mainWindow?.isVisible(); its click calls installDownloadedUpdate() when idle. Delete remind-later, cancel-reminder and the reminder timers. Keep installWhenIdle, add a 5 s cancellable “Restarting in…” before it fires.
  • Just updated: writeUpdaterInstallState also stores notes; reconcileUpdaterInstallState sends updater:updated {version, notes} on success instead of silently clearing.
  • Renderer: UpdateChip gets restart / waiting / restarting / failed; new UpdatePopover (confirm + error); UpdateSheet, WaitingDownloads, hero, deferred view removed; updateModel loses deferred, checking, uptodate views.
  • Settings: row keeps Check now, but its answer shows inline in the hint (Up to date · checked just now) instead of opening a sheet; Restart when ready.

Risks

  • If ignored, the update never installs; a person who never clicks stays on 1.0.0. Optional: install on quit after 7 days (borrowing B).
  • What’s new is only seen after updating; there is no preview before. Full notes stay one click away on GitHub.
  • One-click restart without confirmation: acceptable only because the click is explicit and idle is verified in main.
  • Spec §8.1 and desktop-update-sheet.spec.js would be rewritten.
