B · Banner

A slim, dismissible bar slides in above the queue, in the same place the eye lands after pasting a link. The primary action sits inline, so installing is one click from the main window. What’s new and error details open as a drawer under the bar; everything else stays one line.

Every state

Each bar at full window width, over the first queue row. Number keys 1–9 switch the live window.

Prototype only; nothing here changes the app. The bar’s left edge reuses the row’s 3px accent edge, so it reads as part of the queue’s language.
