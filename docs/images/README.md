# README images

These assets show the current SnagThis interfaces with the fictional download states built into the development galleries. They do not claim real download speeds or successful live-site downloads. No live URLs, accounts, pairing secrets or personal download history appear in them.

- `header.png`: documentation banner with the SnagThis pixel lockup (the same artwork as `apps/desktop/src/assets/snagthis-logo-title.svg`, at 4×). Regenerate it with `node scripts/render-brand-assets.cjs`.
- Everything else is regenerated by `node scripts/capture-readme-media.cjs` (see the comment at the top of that script for the two demo servers it needs). Stills are captured in dark mode at 2× and palettised with ffmpeg.
  - `hero.png`: the desktop gallery (`/?gallery`, 1040 × 700) with the popup (`popup.html?demo`) in front.
  - `desktop.png` and `chrome-extension.png`: plain stills of the same two views. `docs/design/ui-design-spec.md` also uses them.
  - `feature-*.png`: quality picker with an audio sample playing (`?gallery&picker`), popup pairing (`?demo=pairing`), download details (`?gallery&details=1`), Saved shelf (`?gallery&snag=3`, then Saved → Shelf), command palette (`?gallery&palette`) and Appearance with Cobalt chosen (`?gallery&sheet=settings&section=appearance`).
  - `desktop-demo.gif` (880 px, 10 fps): a download finishing, a hover preview, row details, and ⌘K → Show Saved as a shelf.
  - `extension-demo.gif` (560 px, 10 fps): a download finishing, a hover preview, a new download, and switching the accent to Cobalt.

The sample videos are original pixel-art animations made for SnagThis; see the [sample media credits](../../apps/desktop/src/dev/media/CREDITS.md).
