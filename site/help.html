The extension alone, or with the desktop app

The Chrome extension works on its own for simple video files. For everything else, it hands the download to the free SnagThis desktop app for Mac and Windows.

FeatureExtension onlyWith the desktop app
Direct MP4 and WebM filesYesYes
HLS and DASH streamsNoYes
Separate audio tracks, subtitles and joining themNoYes
Links pasted or dropped inNoYes
Where files goChrome DownloadsYour SnagThis folder and the Saved library
SetupNoneConnect once

Keep the desktop app open while it’s downloading. To send a direct file to the app instead of Chrome Downloads, right-click its row in the popup and choose Download with desktop.

Install the extension by hand

The Chrome Web Store listing is on its way. Until it’s live, you can load SnagThis into Chrome yourself. It’s the same extension the store will offer.

  1. Download snagthis-extension.zip and unzip it. Keep the folder somewhere it won’t be deleted: Chrome runs the extension from it.
  2. In Chrome, go to chrome://extensions and turn on Developer mode at the top right.
  3. Choose Load unpacked and select the unzipped snagthis-extension folder.
  4. Click the Extensions puzzle icon and pin SnagThis to the toolbar.

Two things work differently from a store install:

  • No automatic updates. To update, download the new zip, replace the folder’s contents, then click the reload arrow on SnagThis in chrome://extensions. When the store version is available, remove this copy and install that one instead.
  • The desktop app says “Not Web Store” when you connect. That only means it wasn’t installed from the store. Check the four digits match, then choose Allow.

Connect the desktop app

You only need to do this once, and only for downloads that use the desktop app.

  1. Open the SnagThis desktop app. If you don’t have it yet, download it for Mac or Windows. Macs need macOS 13 or later: pick the Apple Silicon build for M-series Macs and the Intel build for older ones (Apple menu → About This Mac shows which you have). Windows needs Windows 10 or later.
  2. In Chrome, click SnagThis in the toolbar (it may be under the Extensions puzzle icon). While the desktop app shows Waiting for Chrome… it asks by itself; otherwise choose Connect in its banner.
  3. SnagThis shows four digits beside Chrome. If Chrome shows the same four, choose Allow in SnagThis. Both close by themselves, and the connection is saved on your computer.

SnagThis didn’t come forward, or you’re connecting another browser?

  1. In the popup, choose Use a code instead.
  2. In the desktop app, open Settings → Chrome extension → Show connection code.
  3. Paste the six-digit code into Chrome. It connects as soon as all six digits are in.

Codes expire after five minutes. Each browser gets its own key, and Disconnect in either app removes it. The extension and the app only talk to each other, on your computer.

Where your files go

  • Saved with the extension alone: your usual Chrome Downloads folder, using Chrome’s download settings. They appear in Chrome Downloads, not in the desktop app’s Saved library.
  • Saved with the desktop app: Downloads/SnagThis by default. You can pick another folder in the app’s settings.

Removing a video from the desktop list keeps its file. Moving the file to the Trash is a separate choice.

Updating SnagThis

The desktop app looks for a new version when it starts and every few hours after that. It downloads the update in the background while you keep snagging.

  1. When the update is ready, a NEW chip with the version number (for example NEW 1.2.0) appears in the top bar.
  2. Click it to see What’s new, then choose Restart & install. SnagThis closes and reopens by itself, and your queue picks up where it left off.
  3. If downloads are still running, tick Install when downloads finish so they aren’t interrupted. Or choose Later and SnagThis reminds you.

To stop the automatic checks, turn off Check automatically in Settings → Updates & support. You can still choose Check now there at any time. The Chrome extension updates through Chrome.

Troubleshooting

Find the message you see below.

No video found

  • Press play on the video. SnagThis spots a video once it starts playing. Then open SnagThis again, or choose Check again.
  • If SnagThis was installed or updated after the page opened, refresh the page, then open SnagThis again.
  • Choose No video? in the popup for these tips at any time.
  • If the popup says This video only plays inside its own player, the site delivers it in a way that only works in its own page, so it can’t be saved.

SnagThis doesn’t save videos from this site

Some sites aren’t supported in the Chrome Web Store version of SnagThis. The video is still listed, dimmed, with this message and no Snag button. Nothing is downloaded or sent to the desktop app.

App not open

  • Start the SnagThis desktop app and keep it open while it downloads.
  • If you’re asked to connect, follow Connect the desktop app.
  • Direct MP4 and WebM files still save with Chrome alone. They don’t need the app.

Link expired

Many sites give a video a link that only works for a while. Reopen the source page, play the video, and open SnagThis again. The download continues from where it stopped.

Download failed

  • Read the message in the popup, or in Chrome Downloads for files saved with Chrome.
  • For desktop downloads, open the row in the app for details.
  • Check that you’re still signed in to the site and that the video still plays there, then try again.

Protected video

Some sites lock their videos with DRM (digital rights management), so they only play inside the site’s own player. SnagThis respects that: it never records, unlocks or saves protected video. This is intentional and there is no setting to change it.

Other videos on the same page that aren’t protected are still listed and can be saved.

SnagThis is for videos you own or have permission to save. Check the site’s terms and the creator’s licence. Live recording isn’t supported.

Reporting a bug

Open an issue on GitHub. Say what you clicked and what message you saw.

The desktop app can export a support bundle from Settings → Support. Web addresses, cookies, tokens and file paths are redacted, but look it over before sharing, and keep cookies, tokens and private video links out of public issues. Report security concerns privately through the security policy.

How SnagThis handles your data is explained in the privacy policy.
